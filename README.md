# AITI Test｜AI Type Index 趣味人格测试网页

AITI Test 是一个基于 **React + Vite** 开发的纯前端趣味测试项目。用户完成 30 道四选一题后，页面会根据选项权重计算人格向量，并生成与 16 个 AI 助手的相似度结果，同时展示主人格、副人格和隐藏 bug 标签。

所有题目、人格标签、AI 权重和图标资源均由本地配置文件管理，便于后续扩展和二次修改。

## 项目特点

- **纯前端实现**：无需后端服务，使用 React 组件完成页面状态管理和交互流程。
- **配置驱动**：题目、选项、人格标签、AI 权重均集中存放在 `public/aiti_v0_1_config.json` 中。
- **人格向量计分**：根据用户选择累加 24 个人格维度分数，形成用户人格画像。
- **AI 相似度匹配**：使用余弦相似度计算用户人格向量与不同 AI 助手权重向量之间的接近程度。
- **结果可视化展示**：展示 Top 5 AI 相似度、主人格、副人格、隐藏 bug 和分享文案。
- **轻量美观界面**：采用深色渐变背景、卡片式布局、进度条、匹配条等视觉元素。
- **易于扩展**：可以直接修改配置文件增加题目、调整权重、更换图标或扩展人格维度。

## 功能说明

### 1. 测试首页

首页展示测试名称、题目数量、AI 助手数量和人格标签数量。用户点击按钮后进入答题流程。

### 2. 题目答题

项目默认包含 30 道四选一题。每个选项都会对应若干人格维度的加分项。用户选择选项后，页面会自动进入下一题，并实时显示答题进度。

### 3. 结果生成

答题完成后，程序会基于用户选择生成结果，包括：

- Top 5 AI 助手相似度
- 主人格标签
- 副人格标签
- 隐藏 bug 标签
- 结果说明文案
- 可复制的分享文本

### 4. 配置化题库

题目与权重存放在：

```text
public/aiti_v0_1_config.json
```

每个选项通过 `scores` 字段设置人格维度分数，例如：

```json
{
  "id": "A",
  "text": "先把问题拆成几个小问题。",
  "scores": {
    "SOLVER": 3,
    "REASONER": 2,
    "PLANNER": 1
  }
}
```

## 计分逻辑

项目的核心计分逻辑位于：

```text
src/utils/scoring.js
```

整体流程如下：

1. 用户每题选择一个选项。
2. 程序读取该选项中的 `scores` 字段。
3. 将所有题目的选项分数累加，得到用户的 24 维人格向量。
4. 将用户人格向量与每个 AI 助手的权重向量计算余弦相似度。
5. 取相似度最高的前 5 个 AI，并通过 softmax 转换为百分比。
6. 根据人格维度分数排序，生成主人格、副人格和隐藏 bug。

其中 `LIAR` 和 `FLATTERER` 被作为隐藏 bug 标签处理，不参与 AI 相似度匹配。

## 本地运行

### 1. 安装 Node.js

建议使用 Node.js 18 或更高版本。

### 2. 安装依赖

```bash
npm install
```

### 3. 启动开发环境

```bash
npm run dev
```

运行后在浏览器打开终端显示的地址，通常为：

```text
http://localhost:5173
```

### 4. 构建生产版本

```bash
npm run build
```

构建结果会输出到：

```text
dist/
```

### 5. 本地预览构建结果

```bash
npm run preview
```

## 如何修改题目

打开：

```text
public/aiti_v0_1_config.json
```

在 `questions` 数组中修改题目文本、选项文本和对应权重即可。

示例结构：

```json
{
  "id": "Q01",
  "text": "面对一个复杂任务，你通常会怎么做？",
  "options": [
    {
      "id": "A",
      "text": "先拆成几个小问题。",
      "scores": {
        "SOLVER": 3,
        "PLANNER": 2
      }
    }
  ]
}
```

## 如何修改 AI 匹配权重

AI 助手画像位于配置文件的 `ai_profiles` 字段中。每个 AI 可以设置：

- 展示名称
- 简短描述
- 图标路径
- 人格权重向量

示例：

```json
{
  "display_name": "Example AI",
  "short_profile": "偏理性、结构化、擅长拆解问题。",
  "icon": "/icons/ai/example.png",
  "weights": {
    "REASONER": 3,
    "SOLVER": 2,
    "PLANNER": 2
  }
}
```

## 如何修改结果文案

结果页文案位于：

```text
src/data/resultCopy.js
```

可以在这里修改不同人格标签对应的标题、说明文字和分享文案。



## 说明

本项目是一个前端互动测试网页，结果主要用于趣味展示和交互体验，不代表严肃心理测评或专业评价。
